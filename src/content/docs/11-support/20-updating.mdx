When a new version of QToys is released, Shopify shows an update notice next to the theme in **Online Store > Themes**.

## Update a theme you haven't edited in code

Click **Update** (or **View update**). Shopify adds the new version to your theme library with your settings, sections and content carried over. Check it in the editor, then publish it.

## Update a theme with code changes

Code edits aren't carried over. Add the new version, then repeat your code changes on it — ideally on a copy — before publishing. Changes made in the **Custom liquid** section or block, and app blocks, carry over automatically.

See the [release notes](/docs/support/release-notes) for what changed in each version.
