QToys is designed so that almost everything can be done in the theme editor. If you still need code changes:

1. **Duplicate the theme first.** In **Online Store > Themes**, click **⋯ > Duplicate** and make changes on the copy. Publish it only when you've tested it.
2. **Prefer the editor's code-free options** — the **Custom liquid** section and block, and app blocks — over editing theme files. They survive theme updates.
3. **Keep a list of your changes.** Edited files aren't updated automatically when a new version of QToys is released, so you'll need to repeat the changes.

## What theme support covers

Theme support covers the theme as we ship it: setup questions, settings and bugs. It doesn't cover custom code, changes made by you or a developer, or third-party apps. See the [support policy](/docs/support/support-policy).

## Hire a Shopify Partner

For custom features or design changes beyond the theme's settings, hire a Shopify Partner from the [Shopify Partner Directory](https://www.shopify.com/partners/directory).
