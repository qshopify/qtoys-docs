## Predictive search

As shoppers type in the header search, QToys suggests related search terms, collections, journal articles and products. Each product suggestion shows its image, name, grow bar, age range and price, so shoppers can tell who a toy is for before they open it. A link at the bottom opens the full results for the search.

Predictive search uses Shopify's own search, so there's nothing to set up. Products without a `custom.age_bands` metafield show no grow bar.

## Search results page

Results are grouped into tabs — **All**, **Products**, **Journal** and **Pages**. Products show as product cards, and articles and pages as text cards. The page has the same filters and sorting as collections, including the [age and skill filters](/docs/collections-and-search/collection-pages#age-and-skill-filters) when you've set them up. When nothing matches, shoppers see a message and can search again from the same page. The default search template ends with a **Featured blog** section.
